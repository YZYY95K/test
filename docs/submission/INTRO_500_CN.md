# DevFlow 参赛简介（约 500 字）

DevFlow 是面向真实软件仓库的可审计多智能体研发系统。它不把多个同质聊天机器人包装成“协同”，而是把问题处理拆为编排、分诊、定位、编码、测试、审查六类不可互换的职责；每个 Agent 只接受自己拥有的 Skill 和结构化交接物，越权、错配、篡改或重复交付会在执行前失败。TeamLeader 维护任务 DAG、失败返回和升级路径，但不能写代码、测试或替代审批；Coder 只能产生 typed patch，Tester 只能在一次性仓库副本中执行服务器预注册命令，Reviewer 不能合并，T4/T5 必须停在人工门。

系统把 MCP 作为安全边界而非工具清单。每次调用同时校验 Agent 身份、活动 Skill、参数、仓库路径、风险等级与签名上下文；危险操作还需绑定精确动作、目标和参数摘要的限时批准。服务端再次授权并写入可验证的 SHA-256 审计链。五个真实 CI/CD MCP 工具已完成服务器闭环：隔离测试、流水线结果、覆盖率、原子回滚和健康检查；凭据通过短期能力句柄在可信适配器内解析，不进入提示词。系统支持 OTLP 追踪、Prometheus 指标、持久化 RAG 与离线降级检索。当前 56 项测试通过，覆盖率 82.73%，六个 Skill 静态质量均为 100/100，并以三个固定版本开源仓库、24 项任务测量正确率、安全率、人工介入率、时延与 token 消耗。DevFlow 的目标不是展示一次幸运演示，而是提供可复制、可拒绝、可恢复、可问责的软件工程协作基础设施。
